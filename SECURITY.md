# Security Policy

## Supported Versions

| Version | Supported |
|:--------|:----------|
| 1.x     | ✅ |

## Reporting a Vulnerability

This is a student project, but we take security seriously.

**Please do not report vulnerabilities via public GitHub issues.**

Instead, email the maintainer directly or open a [security advisory](https://github.com/Volanakis/HorizonView/security/advisories/new).

We aim to acknowledge receipt within 48 hours and provide a fix timeline within 5 business days.
