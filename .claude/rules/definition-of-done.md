# Definition of Done

Multi-agent checklist before a task is marked "Done".

## Pre-Implementation

- [ ] Requirements understood and clarified
- [ ] Technical approach decided
- [ ] Dependencies identified

## Implementation

- [ ] Code written following TypeScript rules
- [ ] No type errors (`npx tsc --noEmit` clean)
- [ ] No lint errors
- [ ] Tests written for new functionality

## Review

- [ ] Security review passed (if applicable)
- [ ] Accessibility check passed
- [ ] Performance considerations addressed

## Verification

- [ ] Dev server starts without errors
- [ ] Feature works as expected
- [ ] Database migrations run successfully
- [ ] No console errors

## Documentation

- [ ] Comments added for complex logic
- [ ] README updated if needed
- [ ] API docs updated (if API changed)

## Cleanup

- [ ] Debug logs removed
- [ ] Console.log statements removed
- [ ] Temporary files deleted
- [ ] TODO comments updated with ticket numbers

## Commit

- [ ] Changes follow conventional commits
- [ ] PR description complete
- [ ] All checks passing
